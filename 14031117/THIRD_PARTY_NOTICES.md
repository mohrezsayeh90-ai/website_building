# Third-party assets

- Font Awesome 4.7.0, obtained from its npm distribution using npm lockfile integrity verification. Font files are licensed under SIL OFL 1.1; CSS code is MIT licensed. See https://fontawesome.com/v4/license/ and the preserved CSS headers.
- DejaVu Sans is included solely as a fallback font. Its license is preserved at `public/ui/fonts/LICENSE-DejaVu.txt`.
- Tailwind CSS 3.4.17 (MIT) generates the bundled fallback utilities. Exact dependency resolutions and integrity hashes are recorded in `package-lock.json`.
- The selected PHP templates and original CSS were supplied by the user and copied without modification. They remain separate from the local renderer and sample data.

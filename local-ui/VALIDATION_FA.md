# شواهد اجرای رابط محلی

این گزارش مربوط به ابزار `local-ui` است؛ نتیجهٔ آن به معنی اجرای سایت عملیاتی اصلی نیست.

- PHP 8.4.24 در محیط لینوکسی اجرا شد. PHP کاربر طبق خروجی ارسالی 8.2.9 است؛ لانچر ویندوز و فایل‌های باینری کاربر در این محیط اجرا نشده‌اند. کد راه‌انداز از قابلیت‌های سازگار با PHP 8.2 استفاده می‌کند.
- نصب PHP به‌صورت محلی و بدون تغییر پیکربندی سیستم، با metadata امضاشده و بسته‌های بررسی‌شدهٔ Debian انجام شد. TLS و امضاها غیرفعال نشدند. اسکریپت نصب در اجرای مجدد runtime موجود را تشخیص داد.
- داشبورد، فهرست پروژه‌ها و شناسنامه با Chromium در اندازه‌های ۱۴۴۰×۱۰۰۰ و ۳۹۰×۸۴۴ باز شدند: هر شش اجرا HTTP 200 داشتند، خطای JavaScript یا درخواست ناموفق و بیرون‌زدگی افقی کل سند ثبت نشد. جدول‌های عریض داخل صفحه اسکرول افقی دارند.
- ۱۹ بررسی عملکردی و پاسخ HTTP موفق بودند: تب‌های جاری و تکمیل‌شده، جست‌وجو، رفتن از پروژه به جزئیات متناظر، ذخیره و بازیابی پیش‌نویس پس از reload، جدابودن اطلاعات دو پروژه، بازگردانی نمونه، اتصال EPL و DPL به همان کد پروژه، پیام محدودیت DCC، منوی موبایل، عدم خطای مرورگر، پاسخ صحیح برای پروژهٔ ناشناخته/ورودی نامعتبر، عدم سرو سورس و رد نوشتن در سرور.
- خواندن یک asset از مسیر خارجی مشخص‌شده با `MEHRABAD_SITE_ROOT` با فایل آزمایشی کنترل‌شده تأیید شد. این آزمون، ظاهر فایل‌های واقعی سیستم ویندوز کاربر را تأیید نمی‌کند.
- PHP router و دو قالب منتخب lint شدند و JavaScript محلی بررسی نحوی شد.
- سرویس آزمایشی متوقف شد و با دستور مستند `bash start-local.sh` دوباره شروع شد؛ درخواست‌های صفحه پس از راه‌اندازی مجدد بررسی شدند.
- کپی دو قالب PHP و ۹ فایل CSS با فایل‌های دریافت‌شدهٔ `bin.rar` مقایسه شد و یکسان بود. پوشهٔ سورس دریافتی و آرشیو قدیمی مخزن تغییر نکردند.
- اطلاعات همهٔ پروژه‌ها ساخته‌شده و آزمایشی‌اند. کنترلر DCC و رمز ایمیل آن وارد بسته نشده است. ورود واقعی، SQL Server، تأیید/امضا، ذخیرهٔ اصلی، ایمیل، خروجی Excel/PDF و فرم کامل EPL/DPL اجرا یا تأیید نشده‌اند.

قالب شناسنامه و جدول پروژه‌ها اصلی‌اند؛ سربرگ، منو و داشبورد برای این ابزار ساخته شده‌اند. تصاویر ثابت مفقود با placeholder مشخص نمایش داده می‌شوند. برای تأیید شباهت دقیق باید اجرای روی ویندوز با فایل‌های اصلی و تصویر مرجع مقایسه شود.

`results.json` جزئیات ۱۹ بررسی موفق را ثبت می‌کند. تصاویر این پوشه با دادهٔ نمونه و فایل‌های جایگزین محیط ابری گرفته شده‌اند. راه‌اندازی یک وظیفهٔ جدید از snapshot و انتشار محیط آزموده نشده‌اند.
